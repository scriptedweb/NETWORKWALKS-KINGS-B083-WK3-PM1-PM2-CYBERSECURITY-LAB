## PDF Password Cracking with John the Ripper

This week's NetworkWalks internship task introduced me to another area of cybersecurity that was completely new to me: **PDF password cracking using John the Ripper**.

For this exercise, I downloaded and set up John the Ripper and worked with a password-protected PDF in the provided lab environment.

### What I did

* Set up **John the Ripper**.
* Used an online hash-cracking/hash-generation tool to extract the hash from the PDF.
* Saved the extracted hash in a `.txt` file.
* Loaded the hash file into John the Ripper.
* Started the cracking process.
* John the Ripper successfully recovered the password to the locked PDF.
* I also explored the **NetworkWalks online hash calculator and password-cracking tool**.

### What I learned

This task gave me practical exposure to how password-protected files can be assessed during authorized security testing and introduced me to another tool used in cybersecurity.

It was another reminder that cybersecurity involves constantly discovering new concepts, tools, and techniques.

**Another unknown knowledge discovered. Another step forward in my cybersecurity journey. 🔐🧩**
